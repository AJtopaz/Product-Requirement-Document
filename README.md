# 📌The Planna - Product-Requirement-Document
End-to-end Product Requirements Document for The Planna, a mobile marketplace designed to simplify event planning by connecting users with verified vendors and planners, while offering tools for both self-coordination and full-service planning.
# 🔹 Overview
The Planna is a mobile marketplace designed to simplify event planning across Nigeria. It connects users with verified event vendors and professional planners, while also supporting those who prefer to coordinate events independently.

This repository contains the Product Requirements Document (PRD) outlining the product vision, user needs, feature set, and MVP scope.
# 🔹 Problem Statement

Event planning in Nigeria is highly fragmented and often relies on word-of-mouth referrals. This creates several challenges:

Difficulty discovering reliable vendors
Lack of transparent pricing
Limited access to trusted reviews
High dependency on full-service planners, which may not be affordable for all users

At the same time, many skilled vendors struggle with visibility and access to new customers.

# 🔹 Proposed Solution

The Planna provides a centralised digital marketplace where:

Users can discover vendors and planners based on location, budget, and event type
Verified reviews and portfolios enable informed decision-making
Users can communicate directly with vendors within the platform
Individuals can either:
Self-manage events using built-in tools, or
Hire planners based on clearly segmented pricing tiers

# 🔹 Target Users
Individuals planning events (weddings, birthdays, corporate events, etc.)
Budget-conscious users who prefer self-coordination
Users seeking full-service event planners
Event vendors (caterers, decorators, photographers, entertainers)
Professional event planners

# 🔹 Key Features (MVP)
Vendor and planner discovery (filters: location, event type, budget)
Vendor profiles with portfolios and verified reviews
In-app messaging between users and service providers
Planner directory segmented by pricing tiers
Self-service event coordination tools

# 🔹 Value Proposition

For users:

Simplifies event planning in one platform
Increases transparency and trust
Supports different budget levels

For vendors & planners:

Increased visibility
Access to a wider customer base
Reduced reliance on referrals

# 🔹 Success Metrics (Example)
Number of active users
Vendor onboarding rate
Conversion rate (search → booking)
User engagement (messages, interactions)
Repeat usage for multiple events
